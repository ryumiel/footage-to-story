# Synthetic contract examples

These seven JSON documents form a small, fictional dataset for schema tests.
They are committed test inputs, not generated job outputs. No source video exists
at the paths in the manifest. No real media analysis or human approval is implied.
The review is deliberately BLOCKED. Its digest is the SHA-256 of the exact bytes
of `edit-plan.json`; editing that fixture requires updating the digest explicitly.

The examples exercise schema conformance only. End-to-end referential integrity,
media verification, export, and Resolve import are not implemented by this set.
